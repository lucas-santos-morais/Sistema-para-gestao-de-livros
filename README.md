# 📚Sistema para gestao de livros

Esse sistema usa linguagem java, usando o "Spring Boot" para realizar toda parte do back-end, css, html e java script complementam o sistema com o front-end. O MySQL faz interação com o spring boot para pegar as informações e funcionar a principal ação que é o foco desse repositório o CRUD (Create, Read, Update e Delete).

## 🛠️Tecnologias usadas

* intellij IDE (Para rodar a parte do back-end)
* Visual Studio (Para rodar a parte do front-end)
* MySQL (Usado para rodar o banco de dados)

## 👅Linguagens trabalhadas
