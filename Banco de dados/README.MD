## 🏦 Banco de dados

Nesta parte temos a pasta com a criação do código em *SQL* para montar o banco de dados que vamos usar.

### 📖 Explicação

Na pasta "biblioteca" tem o código, com a criação do banco de dados e uma tabela de livros criada para usar no projeto. No código tem comentários para facilitar o entendimento.

### 🚨 Observação

Para fazer a integração do nosso banco, saiba qual porta ele está, se tiver senha tambpem será necessário para conectar com o spring boot e o nome do usuário.
